# Obsidian Task Organizer (AOTO)

> **AI-Powered Obsidian Task Organizer**
>
> 전날 적어 둔 무작위 메모와 할 일 목록을 Gemini API 로 정리해 Obsidian 데일리 노트(`.md`)로 바꾸고, Obsidian 보관소(Vault)에 바로 저장하는 웹 앱입니다. 서버 없이 브라우저만으로 동작하므로 Vercel 같은 정적 호스팅에 그대로 배포할 수 있습니다.

---

## 핵심 기능

1. **AI 데일리 노트 변환 (Gemini 2.5 Flash)**
   - 비정형 메모를 이모지 없는 마크다운 문서로 정리합니다.
   - 일정을 **주요일정**, **학교**, **연구실**, **기타** 네 칸으로 나눕니다.
   - '학교' 또는 '졸작' 이라는 낱말이 없는 학업·과제는 **연구실** 칸으로 갑니다.

2. **주간 고정 일정과 유동 일정 통합**
   - **고정 일정**: 요일별 수업·세미나를 적어 두면, 그 요일 노트를 만들 때 **주요일정** 칸에 들어갑니다.
   - **유동 일정**: 주마다 바뀌는 근무표 같은 텍스트를 통째로 붙여 두면, 대상 날짜의 요일에 해당하는 줄만 **주요일정** 칸에 체크박스로 들어갑니다.

3. **월별 하위 폴더 저장**
   - `[하위 폴더]/YYYY-MM/YYYY-MM-DD.md` 경로로 저장합니다. 예: `Daily Notes/2026-11/2026-11-02.md`

4. **미리보기와 병합**
   - 미리보기에서 체크박스를 켜고 끄면 마크다운 원본(`- [ ]` / `- [x]`)이 같이 바뀝니다.
   - 같은 날짜 노트가 보관소에 이미 있으면 **불러와서 합치기**로 기존 체크 상태를 유지한 채 새 할 일을 더합니다(아래 저장 방식 1에서만).

## 저장 방식: 브라우저에 따라 둘로 나뉩니다

| | 1. 폴더 직접 저장 | 2. Obsidian 앱 링크 |
|---|---|---|
| 브라우저 | PC 의 Chrome · Edge | iPhone Safari, Firefox 등 위 둘 외 전부 |
| 동작 | 설정에서 보관소 폴더를 한 번 고르면 그 폴더에 파일을 직접 쓰고 읽음 | 저장 버튼을 누르면 `obsidian://new` 링크로 Obsidian 앱이 열리고 노트가 만들어짐 |
| 필요한 설정 | 보관소 폴더 선택 | 보관소 이름 |
| 기존 노트 불러와서 합치기 | 됨 | 안 됨(같은 날짜 노트는 덮어씀) |
| 재방문 시 | 브라우저를 다시 열면 폴더 접근 허용을 한 번 더 물음 | 추가 동작 없음 |

두 방식 모두 **.md 파일 받기** 버튼으로 파일을 내려받을 수도 있습니다.

iCloud Drive 에 둔 보관소라면, PC 에서는 방식 1로 `iCloud Drive/Obsidian/[보관소 이름]` 폴더를 고르고, iPhone 에서는 방식 2로 같은 보관소 이름을 적으면 됩니다.

## 설정 저장 위치와 API 키

- Gemini API 키, 고정·유동 일정 같은 설정은 **각 사용자 브라우저의 localStorage** 에만 저장됩니다. 서버가 없으므로 배포한 사이트 운영자에게도 키가 전달되지 않습니다.
- API 키는 브라우저에서 Google Gemini API(`generativelanguage.googleapis.com`)로만 보내집니다.
- 브라우저의 저장 데이터를 지우면 설정도 지워집니다. 공용 PC 에서는 키를 입력하지 마세요.
- PC 와 iPhone 은 설정을 따로 저장하므로 기기마다 한 번씩 입력해야 합니다.

[Google AI Studio](https://aistudio.google.com/app/apikey) 에서 API 키를 발급받을 수 있습니다.

## 배포 (Vercel)

1. Vercel 에서 **Add New > Project** 로 이 저장소를 가져옵니다.
2. Framework Preset 은 **Other** 그대로 둡니다. 빌드 단계가 없고, `vercel.json` 이 `public/` 폴더를 배포 대상으로 지정합니다.
3. **Deploy** 를 누르면 `https://<프로젝트 이름>.vercel.app` 주소가 생깁니다.

환경 변수는 필요 없습니다.

## 로컬 실행

```bash
npm run dev
```

`http://localhost:3000` 으로 접속합니다. 폴더 직접 저장(방식 1)은 `https://` 또는 `localhost` 에서만 동작하므로, `index.html` 을 파일로 바로 열지 말고 위 명령으로 띄워야 합니다.

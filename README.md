# Obsidian Task Organizer (AOTO)

> **AI-Powered Obsidian Task Organizer**
> 
> 사용자가 전날 작성한 무작위 메모와 할 일 목록을 AI(Gemini API)를 사용하여 체계적이고 시각적으로 아름다운 Obsidian 데일리 노트 포맷(`.md`)으로 자동 변환하고 로컬 Obsidian Vault 폴더에 직접 연동 저장해주는 프리미엄 로컬 웹 애플리케이션입니다.

---

## 🌟 핵심 기능

1. **지능형 AI 데일리 노트 변환 (Gemini 2.5 Flash)**
   - 비정형 텍스트를 파악하여 이모티콘을 필터링하고 깔끔한 마크다운 문서로 변환합니다.
   - 학업 및 업무 일정을 **주요일정**, **학교**, **연구실**, **기타** 네 가지 직관적인 카테고리로 자동 분류합니다.
   - '학교' 또는 '졸작' 키워드가 명시되지 않은 일반 학업/과제는 기본적으로 **'연구실'** 카테고리로 매핑됩니다.

2. **주간 고정 일정 & 유동 일정 스마트 통합**
   - **고정 일정**: 요일별 학교 수업이나 고정 세미나 일정을 미리 설정해 두면, 해당 요일 노트를 정리할 때 자동으로 삽입됩니다.
   - **유동 일정**: 교대 근무나 변동 시간표 텍스트를 붙여넣어 두면, 오늘의 대상 요일에 해당하는 변동 일정을 똑똑하게 추출하여 **주요일정** 칸에 체크박스로 포함합니다.
   - **기타 일상 분류**: 사용자가 임의로 입력한 일반 일상 용무, 개인 스케줄은 최하단의 **'기타'** 칸에 매칭되어 깔끔하게 분리됩니다.

3. **Obsidian 연/월별 하위 폴더 그룹화**
   - 로컬 보관소 내에 파일들이 뒤섞이지 않도록 날짜를 기준으로 월별 폴더(예: `2026-05/`)를 자동으로 생성하여 문서를 체계적으로 정리합니다.

4. **양방향 인터랙티브 프리뷰 & 지능형 병합 (Merge)**
   - 이미 작성된 데일리 노트가 있을 경우 **"불러와서 합치기"**를 실행할 수 있습니다.
   - 새로운 일정을 추가해도 **기존에 체크 완료된(`- [x]`) 상태는 완벽하게 유지**하면서 새로운 작업들만 병합해 줍니다.
   - 시각적 미리보기 화면에서 마우스로 체크박스를 켜고 끄면 Markdown 원본 코드(`- [ ]` ↔ `- [x]`)가 실시간 양방향 연동됩니다.

5. **심플하고 고급스러운 단색톤 테마 (Minimal Solid-tone Theme)**
   - Obsidian 특유의 절제되고 정갈한 감성을 담은 플랫 다크 차콜 테마와 보라색 악센트를 갖추어 눈의 피로를 최소화하고 사용성을 높였습니다.

## 🚀 시작하기

### 설치 방법

1. 본 레포지토리를 클론합니다:
   ```bash
   git clone <your-repository-url>
   cd scheduler
   ```

2. 종속성 패키지를 설치합니다:
   ```bash
   npm install
   ```

### 실행 방법

#### 방법 A: 바탕화면 원클릭 실행 (추천)
바탕화면에 위치한 **`AOTO 일정 정리.bat`** 파일을 더블 클릭합니다. 
- 환경 변수 오류 방지를 위해 Node.js 절대 경로 구동 방식이 기본 탑재되어 있어 컴퓨터 재부팅 없이 즉시 가동됩니다.
- 실행과 동시에 자동으로 검은색 백엔드 서버 콘솔 창이 뜨며 브라우저 창이 열립니다.

#### 방법 B: 터미널 수동 실행
```bash
node server.js
```
서버 가동 후 브라우저에서 아래 주소로 접속합니다:
👉 [http://localhost:3000](http://localhost:3000)

## ⚙️ 설정 가이드

웹 대시보드 우측 상단의 **설정(⚙️)** 모달에서 아래의 정보를 입력하고 저장합니다.

1. **Gemini API Key**: [Google AI Studio](https://aistudio.google.com/app/apikey)에서 무료로 발급받은 API 키를 입력합니다.
2. **Obsidian Vault 경로**: 사용 중인 로컬 Obsidian 보관소 폴더 경로를 지정합니다.
3. **고정 일정 설정**: 월요일부터 일요일까지의 고정 정기 일정을 기재합니다.
4. **유동 일정 설정**: 매주 변동되는 일정 텍스트를 자유롭게 복사해 넣어둡니다.

## 📱 아이폰(iCloud Drive) 동기화 설정

AOTO는 컴퓨터 폴더에 직접 마크다운 파일을 쓰므로 iCloud Drive를 통해 모바일 기기와 동기화할 수 있습니다.

1. **아이폰**: App Store에서 Obsidian을 설치하고 새 Vault를 만들 때 **Store in iCloud(iCloud에 저장)**를 활성화합니다.
2. **PC**: **Windows용 iCloud** 앱을 설치하고 iCloud Drive를 동기화하여 `iCloud Drive/Obsidian/[보관소 이름]` 경로를 확인합니다.
3. **AOTO**: 위 PC의 iCloud 보관소 경로를 대시보드 설정에 등록하면 PC에서 저장할 때마다 아이폰으로 실시간 동기화됩니다.
